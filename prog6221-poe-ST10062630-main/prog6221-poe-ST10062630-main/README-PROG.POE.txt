Instructions to run and compile software:
=========================================

1. Opening Your Solution - * Launch Visual Studio 2022: Start Visual Studio from your desktop or Start menu.
                           * Open Your Solution: Navigate to the directory where your solution (.sln file) is located.Select the .sln file and click Open.
                           

2. Building (Compiling) Your Project Solution Explorer:

* On the right-hand side of Visual Studio, you'll see the Solution Explorer window. This shows all the projects and files in your solution.
Select Build Configuration:

* At the top toolbar, you'll find a dropdown for Solution Configurations, Choose the configuration you want to build.
Build the Solution:

* Click on Build > Build Solution Visual Studio will compile your project(s) and output any build errors or warnings in the Error List window (usually at the bottom).

3. Running Your Application

* Right-click on the project you want to run in Solution Explorer.
* Click on Debug > Start Debugging or press F5.
* Running Specific Projects:
If your solution contains multiple projects (e.g., a library and an executable), you can set the executable project as the startup project to run directly.

4. Handling Errors and Debugging
* Debugging Tools:
When your application is running in debug mode, you can set breakpoints by clicking in the margin next to a line of code (or pressing F9). This allows you to pause execution and inspect variables, call stack, etc.
*Error Handling:
If there are runtime errors or exceptions, Visual Studio will break at the point of failure and highlight the offending line in the code editor. You can use the Call Stack and Locals windows to diagnose issues.
5. Stopping Your Application
*Stop Debugging:
Click on Debug > Stop Debugging or press Shift + F5 to terminate your running application.
